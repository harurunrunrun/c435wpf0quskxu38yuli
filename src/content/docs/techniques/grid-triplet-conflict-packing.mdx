## 使う場面

格子上の連続する三マスを使って串を作り、マスを重複使用せずに本数を増やしたいときに使います。ここでは中央が `W`、両端が `P` と `G` で、水平・垂直・二つの斜め方向を許す場合を扱います。

一つの候補だけを足す山登り法では、別の串が邪魔になって改善が止まります。追加したい候補と衝突する串を一度に外すと、少ない串への交換も経由して探索できます。固定入力の出力を繰り返し改善する形式に向いています。

## 考え方

まず、各 `W` を中央として、方向 $(0,1),(1,0),(1,1),(1,-1)$ を調べます。両隣が盤内にあり、色が `P/G` または `G/P` なら候補として保存します。逆向きは同じ三マスを表すため、別候補にしません。

各候補を頂点とし、マスを一つでも共有する二候補を辺で結ぶと、同時に使える候補の集合は独立集合です。ただし実装では、辺を全て持つ必要はありません。各マスについて、現在使っている串の候補番号を `owner` に保存します。空きマスは `-1` とします。

使っていない候補を追加するときは、その三マスの所有者を重複なく集めます。この集合を $D$ とすると、消す串は最大三本です。$D$ の串を全て外してから候補を加えるので、本数の変化は $\Delta=1-|D|$ です。既に使っている候補を選んだ場合は、その一本を外し、$\Delta=-1$ とします。

$\Delta\ge0$ の変更は採用し、悪化する変更は温度 $T>0$ に対して $\exp(\Delta/T)$ の確率で採用します。棄却するときは、加えた一本を外し、保存していた $D$ を戻します。一本の衝突串を複数回数えたり、戻す前に新しい串を外し忘れたりしないことが要点です。

現在の解とは別に、探索中の最良解を保存します。全候補を毎回コピーする代わりに、最後の最良更新以降に変更した候補だけを記録できます。最良本数を更新したとき、その候補の採否をまとめて反映します。

## 適用条件

合法な候補を列挙でき、候補間の排他条件がマスの重複だけで決まることが必要です。色の順序が異なる場合、曲がった串を認める場合、候補ごとに重みがある場合には、列挙・評価差・出力形式を合わせて変更します。

掲載実装は各辺が $1$ 以上 $500$ 以下の長方形と、`P/W/G` のみを受け取ります。小盤の検証にも使えるよう、一行や一列も認めています。空盤、空行、不揃いな行、不正な色は例外です。`Model` は構築後に変更せず、それを参照する `Packing` より長く保持します。候補番号は同じ `Model` の中だけで有効です。

有限回の確率的探索に、最大本数や満点の保証はありません。温度、反復回数、乱数の初期値は実験で選びます。実装は反復回数で止めるため、同じ実行環境・入力・初期値・引数で探索を再現できます。固定入力が複数あるときは、それぞれの保存先を分けます。

## なぜ正しいか

合法な串は `W` を中央とする四方向のどれかです。その中央と方向を調べれば必ず列挙され、端の色も検査するので、候補と合法な一本の串が対応します。二本が同時に使えない条件はマスの共有そのものです。したがって、衝突辺を含まない候補集合と合法な串集合が対応します。これは定式化の正しさであり、探索が最大独立集合を発見するという主張ではありません。

現在の集合が合法なら、追加候補に触れる使用中の串は、その三マスの所有者を集めれば全て見つかります。それらを外した後には三マスとも空いているので、追加後も合法です。削除だけでも合法性は保たれます。棄却時に新しい一本を先に外すと、元の合法集合の串をそのまま戻せます。選択配列、所有配列、本数の全てが元に戻ります。

最良解については、最後の更新後に採否が変わった候補を漏れなく記録します。記録されていない候補の採否は最良解と現在解で同じです。記録された候補だけを現在解に合わせれば、その時点の合法集合を正確に保存できます。現在解が後で悪化しても、返す最良解の本数は減りません。

出力は元の盤面をコピーし、選んだ串の中央だけを方向記号に置き換えます。水平は `-`、垂直は `|`、左上と右下を結ぶ方向は `\`、右上と左下を結ぶ方向は `/` です。使われた両端のマスにも元の色を残します。独立した出力検証では、候補番号や所有配列を参照せず、記号から三マスを復元して、中央色・両端色・盤外参照・重複使用・残した文字を検査します。

## 計算量

マス数を $N=RC$、候補数を $M$、探索の反復回数を $I$ とします。各中央について四方向しか調べないため $M\le4N$ で、列挙は $O(N)$ 時間です。変更・復元は最大三本を扱うだけなので一回 $O(1)$ です。

最良解用の差分記録に入る候補は一回の採用につき最大四個です。記録を反映するときに消すので、その総処理時間は $O(I)$ です。初期の貪欲な追加と返却時の再構築も含め、探索全体は $O(N+M+I)$ 時間、$O(N+M)$ 空間です。出力の生成・検証・保存済みファイルの比較はそれぞれ $O(N+M)$ 以内です。

## 実装

`Model(board)` が合法候補を作り、`Packing(model, ids)` が指定した候補集合を持ちます。重複する候補や範囲外の番号には例外を投げます。`apply(id)` は変更を行い、直後の変更だけを `undo(change)` で戻せます。別の操作を挟んで戻したり、返された `Change` を書き換えたりしません。

`anneal(model, iterations, seed, initial)` は、まず `initial` を壊さずに空いた場所へ貪欲に追加し、その後に探索します。開始温度は終了温度以上、両方とも正の有限値とします。反復回数が零でも、最初の貪欲な追加は行います。返り値は探索終了時までの最良集合です。

`answer.output()` で出力盤を作り、`validate_output` で合法性と本数を確認します。前回の出力から再開する場合は、`ids_from_output(model, read_output(path))` を初期集合に渡します。`save_if_better` は合法性を確認し、既存の有効な出力より本数が増えた場合だけ保存します。一時ファイルへの書き込み後も再読込・再検証してから置き換えます。不正な既存出力や既存の一時ファイルがあれば例外になり、保存処理は単一の書き込み元で使います。

```cpp
#include <algorithm>
#include <array>
#include <cmath>
#include <cstdint>
#include <filesystem>
#include <fstream>
#include <random>
#include <stdexcept>
#include <string>
#include <utility>
#include <vector>

namespace triplet_packing {
using Board = std::vector<std::string>;
struct Triplet {
    std::array<int, 3> cell;
    int center;
    char symbol;
};
struct Model {
    Board board;
    int rows, cols;
    std::vector<Triplet> triplets;
    explicit Model(Board input) : board(std::move(input)) {
        if (board.empty() || board.size() > 500 || board[0].empty() ||
            board[0].size() > 500) throw std::invalid_argument("board size");
        rows = int(board.size()); cols = int(board[0].size());
        for (const auto& row : board) {
            if (row.size() != std::size_t(cols)) throw std::invalid_argument("row length");
            for (char ch : row) if (ch != 'P' && ch != 'W' && ch != 'G')
                throw std::invalid_argument("cell color");
        }
        constexpr int dr[4] = {0, 1, 1, 1}, dc[4] = {1, 0, 1, -1};
        constexpr char symbol[4] = {'-', '|', '\\', '/'};
        for (int r = 0; r < rows; ++r) for (int c = 0; c < cols; ++c) {
            if (board[r][c] != 'W') continue;
            for (int d = 0; d < 4; ++d) {
                int a = r - dr[d], b = c - dc[d];
                int x = r + dr[d], y = c + dc[d];
                if (a < 0 || a >= rows || b < 0 || b >= cols ||
                    x < 0 || x >= rows || y < 0 || y >= cols) continue;
                char u = board[a][b], v = board[x][y];
                if ((u == 'P' && v == 'G') || (u == 'G' && v == 'P'))
                    triplets.push_back({{a * cols + b, r * cols + c, x * cols + y},
                                        r * cols + c, symbol[d]});
            }
        }
    }
};

// Candidate IDs are meaningful only for this Model, which must stay unchanged.
class Packing {
public:
    struct Change {
        int added = -1;
        std::array<int, 3> removed{};
        int size = 0, delta = 0;
    };
    explicit Packing(const Model& model, const std::vector<int>& ids = {})
        : model_(&model), take_(model.triplets.size(), 0),
          owner_(model.rows * model.cols, -1) {
        for (int id : ids) {
            check_id(id);
            if (take_[id]) throw std::invalid_argument("duplicate candidate");
            for (int cell : model_->triplets[id].cell)
                if (owner_[cell] != -1) throw std::invalid_argument("overlapping candidates");
            attach(id);
        }
    }
    int score() const { return count_; }
    bool selected(int id) const { check_id(id); return take_[id] != 0; }
    const std::vector<int>& owners() const { return owner_; }
    std::vector<int> ids() const {
        std::vector<int> result;
        for (int id = 0; id < int(take_.size()); ++id) if (take_[id]) result.push_back(id);
        return result;
    }
    bool operator==(const Packing&) const = default;

    // Toggle id. Inserting an absent candidate removes every active blocker.
    Change apply(int id) {
        check_id(id);
        Change change;
        if (take_[id]) {
            change.removed[change.size++] = id;
            detach(id); change.delta = -1;
            return change;
        }
        for (int cell : model_->triplets[id].cell) {
            int other = owner_[cell];
            if (other != -1 && std::find(change.removed.begin(),
                change.removed.begin() + change.size, other) ==
                change.removed.begin() + change.size)
                change.removed[change.size++] = other;
        }
        for (int i = 0; i < change.size; ++i) detach(change.removed[i]);
        attach(id); change.added = id; change.delta = 1 - change.size;
        return change;
    }
    // Only the immediately preceding apply may be undone; do not edit Change.
    void undo(const Change& change) {
        if (change.added != -1) detach(change.added);
        for (int i = 0; i < change.size; ++i) attach(change.removed[i]);
    }
    Board output() const {
        Board result = model_->board;
        for (int id = 0; id < int(take_.size()); ++id) if (take_[id]) {
            const auto& t = model_->triplets[id];
            result[t.center / model_->cols][t.center % model_->cols] = t.symbol;
        }
        return result;
    }
private:
    const Model* model_;
    std::vector<unsigned char> take_;
    std::vector<int> owner_;
    int count_ = 0;
    void check_id(int id) const {
        if (id < 0 || id >= int(take_.size())) throw std::invalid_argument("candidate id");
    }
    void attach(int id) {
        take_[id] = 1; ++count_;
        for (int cell : model_->triplets[id].cell) owner_[cell] = id;
    }
    void detach(int id) {
        take_[id] = 0; --count_;
        for (int cell : model_->triplets[id].cell) owner_[cell] = -1;
    }
};

// Parse output geometry directly: do not consult candidates, IDs, or owners.
int validate_output(const Model& model, const Board& output) {
    if (output.size() != std::size_t(model.rows)) throw std::invalid_argument("output rows");
    for (const auto& row : output)
        if (row.size() != std::size_t(model.cols)) throw std::invalid_argument("output columns");
    std::vector<unsigned char> used(model.rows * model.cols, 0);
    int count = 0;
    for (int r = 0; r < model.rows; ++r) for (int c = 0; c < model.cols; ++c) {
        char ch = output[r][c];
        int dr = 0, dc = 0;
        if (ch == '-') dc = 1;
        else if (ch == '|') dr = 1;
        else if (ch == '\\') dr = dc = 1;
        else if (ch == '/') { dr = 1; dc = -1; }
        else {
            if (ch != model.board[r][c]) throw std::invalid_argument("changed color");
            continue;
        }
        if (model.board[r][c] != 'W') throw std::invalid_argument("center color");
        int a = r - dr, b = c - dc, x = r + dr, y = c + dc;
        if (a < 0 || a >= model.rows || b < 0 || b >= model.cols ||
            x < 0 || x >= model.rows || y < 0 || y >= model.cols)
            throw std::invalid_argument("outside board");
        char u = model.board[a][b], v = model.board[x][y];
        if (!((u == 'P' && v == 'G') || (u == 'G' && v == 'P')))
            throw std::invalid_argument("endpoint colors");
        for (int cell : {a * model.cols + b, r * model.cols + c, x * model.cols + y}) {
            if (used[cell]) throw std::invalid_argument("overlapping output");
            used[cell] = 1;
        }
        ++count;
    }
    return count;
}

std::vector<int> ids_from_output(const Model& model, const Board& output) {
    int count = validate_output(model, output);
    std::vector<int> ids;
    for (int id = 0; id < int(model.triplets.size()); ++id) {
        const auto& t = model.triplets[id];
        if (output[t.center / model.cols][t.center % model.cols] == t.symbol) ids.push_back(id);
    }
    if (int(ids.size()) != count) throw std::logic_error("candidate enumeration mismatch");
    return ids;
}

Packing anneal(const Model& model, int iterations, std::uint64_t seed,
               const std::vector<int>& initial = {},
               double start_temp = 1.5, double end_temp = 0.03) {
    if (iterations < 0 || !std::isfinite(start_temp) || !std::isfinite(end_temp) ||
        end_temp <= 0 || start_temp < end_temp) throw std::invalid_argument("search parameters");
    Packing current(model, initial);
    int m = int(model.triplets.size());
    if (m == 0) return current;
    std::mt19937_64 random(seed);
    std::vector<int> order(m);
    for (int i = 0; i < m; ++i) order[i] = i;
    for (int i = m - 1; i > 0; --i) std::swap(order[i], order[random() % (i + 1)]);
    // Extend the initial packing greedily without displacing its members.
    for (int id : order) {
        if (current.selected(id)) continue;
        bool free = true;
        for (int cell : model.triplets[id].cell) if (current.owners()[cell] != -1) free = false;
        if (free) current.apply(id);
    }
    std::vector<unsigned char> best(m), marked(m, 0);
    for (int id : current.ids()) best[id] = 1;
    int best_score = current.score();
    std::vector<int> dirty;
    auto mark = [&](int id) {
        if (!marked[id]) { marked[id] = 1; dirty.push_back(id); }
    };
    for (int step = 0; step < iterations; ++step) {
        int id = int(random() % m);
        auto change = current.apply(id);
        double fraction = iterations <= 1 ? 0 : double(step) / (iterations - 1);
        double temperature = std::exp((1 - fraction) * std::log(start_temp)
                                      + fraction * std::log(end_temp));
        double u = double(random() >> 11) * 0x1.0p-53;
        bool accept = change.delta >= 0 || u == 0 || std::log(u) < change.delta / temperature;
        if (!accept) { current.undo(change); continue; }
        if (change.added != -1) mark(change.added);
        for (int i = 0; i < change.size; ++i) mark(change.removed[i]);
        if (current.score() > best_score) {
            for (int x : dirty) { best[x] = current.selected(x); marked[x] = 0; }
            dirty.clear(); best_score = current.score();
        }
    }
    std::vector<int> ids;
    for (int id = 0; id < m; ++id) if (best[id]) ids.push_back(id);
    return Packing(model, ids);
}

Board read_output(const std::filesystem::path& path) {
    std::ifstream file(path);
    if (!file) throw std::runtime_error("cannot read output");
    Board rows;
    for (std::string row; std::getline(file, row);) rows.push_back(row);
    if (!file.eof()) throw std::runtime_error("output read failure");
    return rows;
}

// Single writer. The temporary file is placed in the same directory.
bool save_if_better(const Model& model, const std::filesystem::path& path,
                    const Board& candidate) {
    int value = validate_output(model, candidate);
    if (std::filesystem::exists(path) && validate_output(model, read_output(path)) >= value)
        return false;
    auto temporary = path; temporary += ".tmp";
    if (std::filesystem::exists(temporary)) throw std::runtime_error("temporary output exists");
    try {
        std::ofstream file(temporary);
        if (!file) throw std::runtime_error("cannot write output");
        for (const auto& row : candidate) file << row << '\n';
        file.close();
        if (!file) throw std::runtime_error("output write failure");
        Board reloaded = read_output(temporary);
        if (reloaded != candidate || validate_output(model, reloaded) != value)
            throw std::runtime_error("output verification failure");
        std::filesystem::rename(temporary, path);
    } catch (...) {
        std::error_code ignored;
        std::filesystem::remove(temporary, ignored);
        throw;
    }
    return true;
}
} // namespace triplet_packing
```

掲載コードの検証では、`P` の端から八方向へたどる別実装で候補を列挙し、中央から列挙した候補と比較しました。小盤では候補の全ての部分集合を調べて独立に最適値を求め、探索結果がその値を超えないことを確認しています。各合法状態からの追加・削除について、所有配列と本数を再構築し、棄却後の完全一致と同じ操作の再実行も確認します。特定の小盤で最適値に達したという結果を、大盤での最適性保証には使いません。
