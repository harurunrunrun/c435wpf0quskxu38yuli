対象を一つずつ集計する代わりに、各要素が何回含まれるかを数える。

## 使う場面

すべての区間や組の値の合計を求めるときに使う。「各区間の和を求めて足す」前に、「各要素がいくつの区間に含まれるか」を数えると、列挙を省ける場合がある。主客転倒とも呼ばれる。

## 考え方

要素 $i$ の値を $w_i$、その要素を含む対象数を $c_i$ とする。各対象の値が含まれる要素の和なら、全体の合計は $\sum_i w_i c_i$ になる。

長さ $N$ の配列で、添字 $i$ の要素を含む区間は、左端の選び方が $i+1$ 通り、右端の選び方が $N-i$ 通りある。したがって、その要素は $(i+1)(N-i)$ 回足される。全区間を列挙せずに、この係数を各要素へ掛ければよい。

## 適用条件

求める合計を、各要素の寄与の和として表せることが必要になる。最大値や最小値の合計では、その値を担当する要素を各区間で一つに決めれば、同じ考え方を使える場合がある。

同じ値が複数ある場合は、左側を優先するなどの規則を決める。同じ対象を複数の要素が担当して、二度数えてしまわないようにする。

## なぜ正しいか

「対象に含まれる要素」の各組を、対象ごとに足すか要素ごとに足すかの違いである。どちらも同じ組を一度ずつ数えているため、合計は等しい。有限個の和なので、負の値が含まれていても順序を入れ替えられる。

## 計算量

全区間の和の合計の例では、時間 $O(N)$、追加空間 $O(1)$。各区間を列挙する $O(N^2)$ の処理が不要になる。

## 実装

`sum_of_all_subarray_sums` は、すべての非空区間の和を合計した値を返す。係数との積が64ビットを超える場合に備えて、計算と返り値にGNU C++の `__int128` を使う。この型に収まることと、必要な出力処理も確認する。

```cpp
#include <vector>
__int128 sum_of_all_subarray_sums(const std::vector<long long>& a) {
    const long long n = a.size();
    __int128 answer = 0;
    for (long long i = 0; i < n; ++i)
        answer += (__int128)a[i] * (i + 1) * (n - i);
    return answer;
}
```
