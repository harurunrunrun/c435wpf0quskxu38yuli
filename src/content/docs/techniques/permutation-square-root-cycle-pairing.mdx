## 使う場面

順列 $P$ が与えられ、全ての位置で $Q[Q[i]]=P[i]$ となる順列 $Q$ を一つ作る。存在しない場合の判定も必要になる。

対応を二度たどった結果が一致するように、サイクルのつなぎ方を決める。

## 考え方

$P$ を互いに素なサイクルへ分解する。サイクルを $(c_0,\ldots,c_{k-1})$ と書くと、$P[c_j]=c_{(j+1)\bmod k}$。

**$k$ が奇数なら、そのサイクルだけで作れる。** $s=(k+1)/2$ とし、

$$Q[c_j]=c_{(j+s)\bmod k}$$

と置く。二度の移動幅は $2s=k+1$ なので、$P$ の一歩になる。長さ1の固定点もこの式に含まれる。

**$k$ が偶数なら、同じ長さの別のサイクルと組にする。** 二本を $(a_0,\ldots,a_{k-1})$、$(b_0,\ldots,b_{k-1})$ とすると、

$$Q[a_j]=b_j,\qquad Q[b_j]=a_{(j+1)\bmod k}$$

と置く。つまり $a_0,b_0,a_1,b_1,\ldots$ の順に一つのサイクルへつなぐ。同じ偶数長のサイクルが奇数本残る長さがあれば、構築不能になる。

例えば $P=(0\ 1)(2\ 3)$ なら、$Q=(0\ 2\ 1\ 3)$ とできる。一方、$P=(0\ 1)$ の一本だけでは作れない。

## 適用条件

入力は、全要素がちょうど一度ずつ現れる順列。求める写像も順列で、合成回数は二回である。一般の関数グラフには木の部分もあるため、このサイクルだけの条件では判定できない。

**存在条件は、各偶数 $k$ について、長さ $k$ のサイクルの本数が偶数であること。** 奇数長のサイクルの本数には制約がない。異なる長さの偶数サイクルを組にしても解決しない。三乗根などでは、長さと合成回数の最大公約数に合わせて条件を立て直す。

## なぜ正しいか

まず $Q$ の長さ $r$ のサイクルを二度ずつたどる場合を考える。$r$ が奇数なら、2と $r$ が互いに素なので全頂点を巡る一本の長さ $r$ のサイクルになる。$r$ が偶数なら、偶数番目と奇数番目に分かれ、長さ $r/2$ の二本になる。

従って、$P$ の偶数長 $k$ のサイクルは、$Q$ の長さ $2k$ のサイクルから必ず二本ずつ生じる。これが本数の偶奇条件の必要性である。

逆に、上の奇数長の式は二度適用すると添字が一つ進む。偶数長の二本の式も、$a_j$ は $b_j$ を経て $a_{j+1}$ へ、$b_j$ は $a_{j+1}$ を経て $b_{j+1}$ へ進む。どちらも元の $P$ と一致し、各頂点の行き先と入ってくる元が一つずつ定まるため、$Q$ も順列になる。全ての偶数長のサイクルを組にできれば十分である。

## 計算量

入力検証、サイクル分解、構築は全て $O(N)$ 時間。未処理の偶数長サイクルを長さで引く配列、訪問済み配列、答え、現在のサイクルを合わせて $O(N)$ 空間。長さをキーにして整列する必要はない。

## 実装

`permutation_square_root(p)` は0始まりの順列を受け取る。解があれば `q`、なければ `nullopt` を返す。重複や範囲外を含む入力は `invalid_argument` にする。順列の長さは `INT_MAX` 未満とし、それ以上は `length_error` にする。空の順列には空の平方根を返す。再帰は使わない。

同じ偶数長の相手を待つときは、サイクルの先頭頂点だけを保存する。二本目が来たら、一方はサイクル配列、他方は $P$ の辺をたどって同時に進める。

```cpp
#include <bits/stdc++.h>
using namespace std;

optional<vector<int>> permutation_square_root(const vector<int>& p) {
    if (p.size() >= static_cast<size_t>(INT_MAX))
        throw length_error("permutation too long");
    const int n = static_cast<int>(p.size());
    vector<unsigned char> used(n, 0);
    for (int x : p) {
        if (x < 0 || x >= n || used[x])
            throw invalid_argument("not a permutation");
        used[x] = 1;
    }
    fill(used.begin(), used.end(), 0);
    vector<int> q(n, -1), waiting(n + 1, -1);
    for (int start = 0; start < n; ++start) {
        if (used[start]) continue;
        vector<int> cycle;
        for (int v = start; !used[v]; v = p[v]) {
            used[v] = 1;
            cycle.push_back(v);
        }
        const int k = static_cast<int>(cycle.size());
        if (k % 2 == 1) {
            const int shift = (k + 1) / 2;
            for (int j = 0; j < k; ++j)
                q[cycle[j]] = cycle[(static_cast<size_t>(j) + shift) % k];
        } else if (waiting[k] == -1) {
            waiting[k] = start;
        } else {
            int a = waiting[k];
            for (int b : cycle) {
                q[a] = b;
                q[b] = p[a];
                a = p[a];
            }
            waiting[k] = -1;
        }
    }
    for (int start : waiting)
        if (start != -1) return nullopt;
    return q;
}
```
