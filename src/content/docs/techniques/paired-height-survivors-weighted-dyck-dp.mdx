## 使う場面

高さ $1,\ldots,N$ が各二回現れる列で、同じ正の高さのうち最後の位置だけを保護し、それ以外の正の高さを同時に一つ減らします。この操作を $N$ 回行い、正のまま残る位置の集合から元の重複順列を数えるときに使います。

操作履歴を保存する代わりに、左から読んだ位置の高さ頻度を考えます。残らない位置の一部の高さを未決定にしておけば、確定済みの高さの範囲だけで状態を表せます。その範囲が伸びるときの係数が、三値のDyck列の重みになります。以下はこの「各高さ二本・右端を保護」という条件に特化した計数です。

## 考え方

位置 $i$ より前に現れた高さ $h$ の個数を $B_h$ とし、

$$
P_0=0,\qquad P_\ell=\sum_{h=1}^{\ell}(B_h-1)
$$

とします。$P_0,\ldots,P_N$ が最小になる**最初の添字**を $r$ とすると、現在の高さ $a$ が残る条件は $a>r$ です。同値な形は

$$
\exists k\in[1,a]:\quad
\sum_{h=k}^{\ell}(B_h-1)\ge0\quad(k\le\ell\le N)
$$

です。これは位置の接頭辞を高さの順に並べ直した頻度条件であり、元の位置の接頭辞和ではありません。

ここからは $B_h$ を「既に読んだ、残らない位置だけの高さ $h$ の個数」とします。この変更でも $r$ は同じです。また $P_r=P_N$ が保たれます。したがって高さ $r+1,\ldots,N$ の歩幅 $B_h-1\in\{-1,0,1\}$ は、途中で負にならず、最後に0へ戻る列です。これを三値Dyck列と呼びます。長さを $j=N-r$ とすると、この範囲には残らないコピーがちょうど $j$ 個あります。

高さ $h$ の二本を $h,h'$ と区別して数えます。$i$ 個の位置を処理した状態 $dp[j]$ は、高さ $N-j+1,\ldots,N$ のコピーを置いた位置を決め、その範囲より下の「残らない位置」の高さを未決定にした場合の数です。これまでの残る位置数を $s$、残らない位置数を $m=i-s$ とします。未決定位置は $m-j$ 個です。

次が残る位置なら、その高さは確定済みの範囲に入ります。そこには全 $2j$ コピー中、残らない位置で $j$ 個、残る位置で $s$ 個を使っているので、残る選択肢は $j-s$ 個です。

$$
next[j]\mathrel{+}=dp[j](j-s).
$$

次が残らない位置なら、未決定のままにする遷移 $next[j]\mathrel{+}=dp[j]$ と、確定範囲を $x\ge1$ 高さ分だけ下へ伸ばす遷移があります。後者では新しい三値Dyck列 $S$ の長さが $x$、使用コピー数も $x$ です。最後の、途中で0に触れない成分の長さを $y$ とします。水平一歩の列も長さ1の成分に含めます。

現在の位置には、その最後の成分に属する使用コピーのどれかを置きます。このコピー数は $y$ です。**異なる高さが $y$ 種類あるという意味ではありません。** 同じ高さの二コピーを含む場合も、ラベル付きの二つの選択として数えます。残りの $x-1$ 位置を過去の未決定位置から選んで並べる方法は

$$
\binom{m-j}{x-1}(x-1)!
$$

通りです。

歩幅 $-1,0,1$ は、その高さの使用コピー数 $0,1,2$ に対応します。使用するラベルの部分集合の数はそれぞれ $1,2,1$ なので、列の重みを

$$
w(S)=\prod_t(2-|S_t|)
$$

とします。例えば $S=(1,0,-1)$ なら使用数は $(2,1,0)$ です。真ん中の高さでラベルを二通りから選び、現在の位置には使用する三コピーのどれかを置けるため、列の重みは2、現在のコピーの選択数は3になります。

長さ $t$ の三値Dyck列の重みの総和を $D_t$、途中で0に触れないものの総和を $I_t$ と置くと、

$$
\begin{aligned}
D_0&=1,\\
D_t&=2D_{t-1}+\sum_{u=0}^{t-2}D_uD_{t-2-u}\quad(t\ge1),\\
I_1&=2,\qquad I_t=D_{t-2}\quad(t\ge2)
\end{aligned}
$$

です。第一項は水平一歩、和は上昇一歩と対応する下降一歩の間の列・その後ろの列です。$t=1$ の和は空です。

さらに

$$
K_x=\sum_{y=1}^{x}yD_{x-y}I_y
$$

を前計算すると、伸長遷移は

$$
next[j+x]\mathrel{+}=
dp[j]\binom{m-j}{x-1}(x-1)!K_x
$$

になります。$1\le x\le\min(N-j,m-j+1)$ を試します。$D,I,K$ を先に計算することで、各遷移の中で $y$ を列挙する必要がなくなります。実装は $F[u][v]=u(u-1)\cdots(u-v+1)$ を前計算し、二項係数と階乗の積を $F[m-j][x-1]$ として使います。

初期値は $dp[0]=1$ です。全位置の処理後は $j=N$ の状態だけを取り、コピーのラベルを外すため $2^N$ で割ります。

## 適用条件

高さが連続する $1,\ldots,N$ に各二本あり、保護するのが同じ高さの最後の位置であることが必要です。操作は同じ時刻の高さを使って一斉に行います。このとき $t$ 回後の高さ別本数は、$1\le h\le N-t$ では二本、$N-t<h\le N$ では一本です。よって $N$ 回後には高さ $1,\ldots,N$ に一本ずつ残ります。

三本以上ずつある場合は歩幅もコピーの重みも変わります。保護する位置の規則を変えたり、高さに欠番があったりする場合も、以下の閾値と係数はそのまま使えません。法は固定の素数 $10^9+7$ です。

位置集合そのものが不可能なこともあります。残る位置を昇順に $A_1,\ldots,A_N$ とすると、少なくとも $A_t\ge2t$ が必要です。残る $t$ 本目を置く直前に $j\ge t$、かつ $j\le m$ が必要だからです。この条件を満たさない入力にも、掲載APIは個数0を返します。

## なぜ正しいか

まず操作と静的な割当ての同値性を示します。右側の位置だけを見ると、いったん正の高さ $h$ に一本でも存在すれば、次の操作でもその高さの最後の一本が保護されるため、高さ $h$ が空になることはありません。右から位置を確定すると、現在の高さ $a$ の位置は、右側の位置が最終的に占める高さを通過して、$a$ 以下で最も高い空き高さに止まります。空きがなければ0まで落ちます。右側が使う高さへ止まり続けることはできず、最後まで空いている高さを通過することもできません。前節の本数の帰納式により、実際に $N$ 回でこの安定状態へ到達します。

この空き高さへの割当てでは、右側の高さの多重集合だけで占有される高さが決まります。高さの上から、まだ割り当てていないコピーを一つ空き枠へ入れ、余りを下へ送ればよいからです。現在の高さを $a$ とし、右側の初期頻度を

$$
C_h=2-B_h-[h=a],\qquad
R_\ell=\sum_{h=1}^{\ell}(C_h-1)
       =-P_\ell-[a\le\ell]
$$

とします。高さ $q$ が空くのは、そこが高さ $q$ 以上のコピーから埋められないときです。上から余りを送る計算では、これは

$$
R_{q-1}>\max_{q\le\ell\le N}R_\ell
$$

と同値です。実際、右辺との差が正になるには $C_q=0$ が必要で、さらに $q$ より上のどの区間からも余りが来ないことを表しています。$1,\ldots,a$ に空きがある条件は、これらの厳密な右側最大記録が少なくとも一つある条件、すなわち

$$
\max_{0\le\ell<a}R_\ell>
\max_{a\le\ell\le N}R_\ell
\iff
\min_{0\le\ell<a}P_\ell\le
\min_{a\le\ell\le N}P_\ell
$$

です。最後の同値は $P_\ell$ が整数であることを使います。これが、最初の最小点が $a$ より前にある条件です。

次に、残る位置を頻度から外せる理由を示します。ある高さ $a$ を加えると、頻度の歩行では添字 $a$ 以降に一律1を加えます。最初の最小点が $r$ のとき、$a>r$ なら最小点は変わりません。$a\le r$ なら最小点は左へ動くか、その場にとどまります。残らない位置だけを追加する歩行では、初期状態からずっと $P_r=P_N$ です。追加前の $r$ より左の値は最小値より少なくとも1大きいため、追加後も端点が最小値になります。また、過去に残った高さは当時の $r$ より大きく、その後の $r$ は増えません。その寄与を戻しても現在の最初の最小点は変わりません。従って、残らない位置の頻度だけで同じ生存判定ができます。

最後に伸長係数を確認します。新たな帯の三値Dyck列を $S$ とします。現在の位置のコピーを取り除いた状態で以前の境界を保つには、コピーの高さから帯の右端の一つ手前まで、$S$ の累積和が全て正である必要があります。これは、そのコピーが最後の0から後、つまり最後の原始成分に属する条件です。使用コピーはその成分に $y$ 個あるので、現在のコピーの選択は $y$ 通りになります。

一度そのコピーを除けば、残るコピーの任意の部分集合を既に置いていても、古い境界を越えるDyckの接尾辞は作れません。従って、選んだ過去の未決定位置は、それぞれを読んだ時点でも残らず、境界を変えません。逆に、元の完成列から新しく確定した帯・最後の成分・そこへ置いた位置とコピーは一意に取り出せます。列の重み、過去の位置の選択と並べ方、現在のコピーの選択の積で、漏れも重複もなく数えられます。低いままの未決定位置は、後の帯の伸長で同じ方法により確定します。

区別しない各完成列について、高さごとの二つの位置へ $h,h'$ を置く方法はちょうど二通りです。ラベルは操作にも生存判定にも影響せず、各高さで独立なので、ラベル付き完成列は正確に $2^N$ 倍です。最後に $2^{-N}\bmod(10^9+7)$ を掛ければ求める個数になります。

## 計算量

$D,I,K,F$ の前計算は時間・空間ともに $O(N^2)$ です。各位置で $j$ と伸長幅 $x$ を列挙するため、本体は $O(N^3)$ 時間です。残らない位置の直前の個数を $m$ とすれば、伸長の試行数は全体で高々 $\sum_{m=0}^{N-1}(m+1)(m+2)/2=O(N^3)$ になります。残る位置の処理は合計 $O(N^2)$ です。DPは二行だけ保存し、総空間は $F$ の $O(N^2)$ です。$N\le600$ に対応します。

## 実装

`count_paired_height_survivors(n, surviving_positions)` は、1始まり・昇順の残る位置を $n$ 個受け取り、個数を $10^9+7$ で割った余りとして返します。$1\le n\le600$、要素数、範囲、厳密な昇順を検査し、契約違反は `invalid_argument` にします。形式が正しくても実現できない集合は0です。入力は変更しません。

剰余どうしの積は $(10^9+7)^2<2^{63}$ で、加算後も `long long` に収まります。$y$ や下降階乗の次の因子は600以下です。各積・加算の直後に剰余を取ります。

```cpp
#include <bits/stdc++.h>
using namespace std;

long long count_paired_height_survivors(
    int n, const vector<int>& surviving_positions) {
    constexpr long long mod = 1000000007;
    constexpr long long inverse_two = 500000004;
    if (n < 1 || n > 600 || surviving_positions.size() != size_t(n))
        throw invalid_argument("require 1 <= n <= 600 and n positions");
    vector<bool> survives(2 * n + 1);
    int previous = 0;
    for (int position : surviving_positions) {
        if (position <= previous || position > 2 * n)
            throw invalid_argument("positions must increase in [1, 2n]");
        survives[position] = true;
        previous = position;
    }

    // D[t]: weighted nonnegative walks of length t returning to zero.
    vector<long long> dyck(n + 1), primitive(n + 1), kernel(n + 1);
    dyck[0] = 1;
    for (int t = 1; t <= n; ++t) {
        dyck[t] = 2 * dyck[t - 1] % mod;
        for (int u = 0; u + 2 <= t; ++u)
            dyck[t] = (dyck[t] + dyck[u] * dyck[t - 2 - u]) % mod;
        primitive[t] = t == 1 ? 2 : dyck[t - 2];
        for (int y = 1; y <= t; ++y) {
            long long term = dyck[t - y] * primitive[y] % mod;
            kernel[t] = (kernel[t] + term * y) % mod;
        }
    }
    // F[u][v] = binom(u, v) * v!.
    vector<vector<long long>> falling(n + 1, vector<long long>(n + 1));
    for (int u = 0; u <= n; ++u) {
        falling[u][0] = 1;
        for (int v = 1; v <= u; ++v)
            falling[u][v] = falling[u][v - 1] * (u - v + 1) % mod;
    }

    vector<long long> dp(n + 1), next(n + 1);
    dp[0] = 1;
    int kept = 0, lost = 0;
    for (int position = 1; position <= 2 * n; ++position) {
        fill(next.begin(), next.end(), 0);
        if (survives[position]) {
            for (int j = kept + 1; j <= lost; ++j)
                next[j] = dp[j] * (j - kept) % mod;
            ++kept;
        } else {
            for (int j = 0; j <= lost; ++j) {
                if (dp[j] == 0) continue;
                next[j] = (next[j] + dp[j]) % mod;
                int undecided = lost - j;
                int limit = min(n - j, undecided + 1);
                for (int x = 1; x <= limit; ++x) {
                    long long ways = falling[undecided][x - 1] * kernel[x] % mod;
                    next[j + x] = (next[j + x] + dp[j] * ways) % mod;
                }
            }
            ++lost;
        }
        dp.swap(next);
    }
    long long answer = dp[n];
    for (int h = 0; h < n; ++h) answer = answer * inverse_two % mod;
    return answer;
}
```
